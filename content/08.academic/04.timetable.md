# Timetables

The timetable organizes the weekly schedule of classes, teachers, and rooms. Directors and administrators create and manage the timetable to ensure efficient use of school resources.

## Creating a Timetable

1. Navigate to **Timetable** in the sidebar
2. Click **Create Timetable**
3. Select the academic year and term
4. Set the week structure (e.g., 5-day week)
5. Click **Save**

## Adding Periods

1. Open a timetable
2. Click **Add Period**
3. Set the details:
   - **Day** — Monday through Friday
   - **Time** — Start and end time
   - **Class** — Which class the period is for
   - **Subject** — Which subject is taught
   - **Teacher** — Which teacher teaches the period
   - **Room** — Which classroom is used
4. Click **Save**

## Timetable Views

| View | Description |
|------|-------------|
| **Daily View** | Shows all periods for a single day |
| **Weekly View** | Shows the full week schedule |
| **Teacher View** | Shows all periods for a specific teacher |
| **Class View** | Shows all periods for a specific class |

## Timetable Features

- **Period Times** — Configurable period durations and breaks
- **Siren Integration** — Bell schedules linked to period times
- **Room Management** — Track which rooms are used for which periods
- **Teacher Scheduling** — Ensure teachers aren't double-booked
- **Student Timetable** — Students can view their own timetable

> [!TIP]
> The **Current Period** badge on the Teacher Dashboard shows which period is active right now. This updates automatically based on the timetable schedule.
