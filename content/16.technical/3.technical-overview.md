│   Frontend   │     │   Backend   │     │  Database   │

## Tech Stack

| Layer | Technology |
|-------|-----------|
| **Backend** | NestJS, PostgreSQL, Prisma, BullMQ + Redis, JWT + RBAC |
| **Frontend** | Next.js (App Router), Tailwind CSS, shadcn/ui, React Query, Dexie (IndexedDB) |
| **Notifications** | In-app, Web Push, Email, SMS, Telegram |
| **AI** | OpenRouter-compatible LLM client with tool calling and streaming |
| **Infra** | Docker Compose (dev & prod), nginx, pgBouncer |

## Key Technologies

- **Next.js** — Frontend framework with App Router
- **NestJS** — Backend framework with module architecture
- **Prisma** — ORM with type-safe database access
- **BullMQ** — Job queue for background tasks
- **Redis** — Cache and message broker
- **PostgreSQL** — Primary database
- **Dexie** — IndexedDB wrapper for offline-first PWA
- **Tailwind CSS** — Utility-first CSS framework
- **shadcn/ui** — Component library
