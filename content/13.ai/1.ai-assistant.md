# AI Assistant

YeneSchool includes an integrated AI assistant that helps teachers, students, and administrators with school-related tasks. The AI assistant uses a streaming chat interface with school-data tools and role-aware responses.

## Accessing the AI Assistant

1. Look for the **Assistant** icon in the header
2. Click to open the chat panel
3. Type your question or request
4. The AI responds with streaming text

## AI Assistant Features

| Feature | Description |
|---------|-------------|
| **Streaming Chat** | Real-time streaming responses |
| **School Data Tools** | Access to student records, grades, attendance |
| **Role-Aware Responses** | Responses tailored to your role |
| **File Attachments** | Upload PDFs or text files for analysis |
| **Translation** | Dynamic AI translation between 5 languages |
| **Ethiopian Calendar** | Understands and works with Ethiopian dates |

## AI Capabilities

### For Teachers
- Generate lesson plans and assignments
- Grade student work with suggestions
- Create exam questions
- Summarize student performance

### For Students
- Answer homework questions
- Explain concepts
- Help with study planning
- Translate assignments to local languages

### For Administrators
- Generate reports and summaries
- Analyze attendance and grade trends
- Answer questions about school policies
- Assist with scheduling

## AI Configuration

The AI assistant uses OpenRouter-compatible providers. Configure it in **Settings → Platform Settings**:

1. Set the AI provider (API key and model)
2. Configure role-specific AI assistants
3. Set up translation preferences
4. Define data access permissions

> [!WARNING]
> AI features require an API key and model configuration. Contact your system administrator to set up the AI service.
