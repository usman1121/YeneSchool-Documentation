# AI Assistant Overview

The YeneSchool AI Assistant is an integrated AI that helps teachers, students, and administrators with school-related tasks. It uses streaming chat with school-data tools and supports 5 languages.

## Module Map

| Feature | Description |
|---------|-------------|
| **Streaming Chat** | Real-time streaming responses |
| **School Data Tools** | Access to student records, grades, attendance |
| **Role-Aware Responses** | Tailored to your user role |
| **File Attachments** | Upload PDFs or text files for analysis |
| **Translation** | Dynamic AI translation between 5 languages |
| **Ethiopian Calendar** | Understands and works with Ethiopian dates |

## Role-Specific Copilots

| Role | Copilot Focus |
|------|---------------|
| **Teacher** | Lesson planning, grading, student analysis |
| **Student** | Homework help, study planning, translation |
| **Director** | Reports, analytics, policy guidance |
| **Registrar** | Enrollment, student records, CSV processing |
| **Finance** | Fee analysis, payment tracking, overdue reports |
| **Parent** | Attendance, grades, school updates |

## AI Capabilities

### For Teachers
- Generate lesson plans and assignments
- Grade student work with suggestions
- Create exam questions
- Summarize student performance

### For Students
- Answer homework questions
- Explain concepts
- Help with study planning
- Translate assignments to local languages

### For Administrators
- Generate reports and summaries
- Analyze attendance and grade trends
- Answer questions about school policies
- Assist with scheduling

> [!NOTE]
> The AI assistant requires an OpenRouter-compatible provider configuration. Contact your system administrator to set up the AI service.
