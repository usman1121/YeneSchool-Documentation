# AI Assistant Configuration

Configure the AI assistant to work with your school's data and needs — set up providers, manage permissions, and customize role-specific copilots.

## Provider Setup

YeneSchool uses OpenRouter-compatible LLM providers. To configure:

1. Navigate to **Platform Settings → AI Configuration**
2. Set the API endpoint URL
3. Enter your API key
4. Select the default model
5. Click **Save**

## Role-Specific Copilots

Each role can have a customized AI copilot:

| Role | Copilot Focus |
|------|---------------|
| **Teacher** | Lesson planning, grading, student analysis |
| **Student** | Homework help, study planning, translation |
| **Director** | Reports, analytics, policy guidance |
| **Registrar** | Enrollment, student records, CSV processing |
| **Finance** | Fee analysis, payment tracking, overdue reports |
| **Parent** | Attendance, grades, school updates |

## Data Access Permissions

Control what data the AI can access:

1. Go to **Platform Settings → AI Permissions**
2. Select which data types the AI can access:
   - Student records
   - Grades and marks
   - Attendance records
   - Financial data
   - Communication history
3. Set role-specific access levels
4. Click **Save**

## Translation Configuration

The AI assistant supports dynamic translation between languages:

1. Go to **Platform Settings → Translation**
2. Select available languages (Amharic, Afaan Oromo, Somali, Arabic, English)
3. Enable automatic translation for AI responses
4. Set the default language for each role

> [!NOTE]
> The AI assistant supports **5 languages**: Amharic (አማርኛ), Afaan Oromo, Somali (Soomaaliga), Arabic (العربية), and English.
