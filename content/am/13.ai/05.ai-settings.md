# የAI ረዳት ውቅር እና የሞዴል ቅንብሮች

የትምህርት ቤት ዳይሬክተሮች እና የሥርዓት አስተዳዳሪዎች የAI የማሰብ ችሎታን ሞተር በትምህርት ቤቱ ዙሪያ ከ**ዳይሬክተር ፖርታል > የትምህርት ቤት ቅንብሮች > AI ውቅር** ማዋቀር፣ ማበጀት እና መከታተል ይችላሉ።

---

## 1. የአገልግሎት ሰጪ እና የLLM ሞዴል ማዋቀር

YeneSchool ከOpenRouter ጋር ተኳሃኝ የLLM መዳረሻ ነጥቦችን እንዲሁም ቀጥተኛ የአገልግሎት ሰጪ ውህደቶችን በተፈጥሮ ይደግፋል፦

```
┌────────────────────────────────────────────────────────────────────────┐
│ ⚙️ AI Engine Configuration                                             │
├────────────────────────────────────────────────────────────────────────┤
│ Provider:               [OpenRouter (Recommended)         ▼]           │
│ API Key:                [••••••••••••••••••••••••••••••••] [Test Key]  │
│ Primary Model:          [anthropic/claude-3.5-sonnet       ▼]           │
│ Fast / Utility Model:   [google/gemini-2.0-flash           ▼]           │
│ Temperature:            [0.3 (Deterministic / Pedagogical) ▼]          │
└────────────────────────────────────────────────────────────────────────┘
```

1. ወደ **ዳይሬክተር ፖርታል > የትምህርት ቤት ቅንብሮች > AI ውቅር** ይሂዱ።
2. **የOpenRouter API ቁልፍዎን** ወይም ብጁ የመግቢያ URL ያስገቡ።
3. የሚመርጧቸውን ሞዴሎች ይምረጡ፦
   - **ዋና ሞዴል፦** ለጥልቅ የ5E ትምህርት እቅድ፣ ለፈተና ጥያቄ ማመንጨት እና ለውስብስብ የአደጋ ምርመራዎች ይጠቅማል።
   - **ፈጣን ሞዴል፦** ለእውነተኛ-ጊዜ የቀጥታ ስርጭት ቻት፣ ለፈጣን ትርጉሞች እና ለማለዳ የተመሩ ማጠቃለያዎች ይጠቅማል።
4. የAPI ቁልፉን ትክክለኛነት እና የኮታ ሁኔታን ለማረጋገጥ **ግንኙነት ይፈትሹ** የሚለውን ይጫኑ።
5. **ውቅሩን ያስቀምጡ** የሚለውን ይጫኑ።

## 3. የቶከን በጀቶች እና የመጠን ገደብ

ያልተጠበቁ የAPI ወጪዎችን ለመከላከል እና ፍትሃዊ ተደራሽነትን ለማረጋገጥ፦
- **በሚና የዕለት የቶከን ገደቦች፦** ለመምህራን፣ ለተማሪዎች እና ለአስተዳደር ሰራተኞች ከፍተኛ የማመንጨት ገደቦችን ያዘጋጁ።
- **የአውድ መስኮት መሸጎጫ፦** በተመሳሳይ የትምህርት ቤት ሥርዓተ-ትምህርት ክፍሎች ላይ የሚደረጉ ተደጋጋሚ ጥያቄዎች የቶከን ፍጆታን እስከ 60% ለመቀነስ በRedis ውስጥ ይቀመጣሉ።
