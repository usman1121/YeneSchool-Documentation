# የወላጅ ዳሽቦርድ አጠቃላይ እይታ

**የወላጅ ዳሽቦርድ (Parent Dashboard)** ስለ ልጅዎ የትምህርት ቤት ህይወት መረጃ እንዲያውቁ የሚያደርግዎ ማዕከላዊ መገናኛ ነው። በወላጅ አካውንትዎ አንዴ ከገቡ፣ ከመገለጫዎ ጋር የተገናኙ ልጆችን ብቻ የሚያሳይ ግላዊ እይታ ያያሉ።

## ምን ማድረግ ይችላሉ

| ክፍል | የሚያዩት |
|---|---|
| **አጠቃላይ እይታ** | የመገኘት መጠን፣ መጪ ፈተናዎች፣ የክፍያ ቀሪ ሂሳብ በአንድ እይታ |
| **መገኘት** | የዕለታዊ መዝገቦች እና የወርሃዊ የቀን መቁጠሪያ ለእያንዳንዱ ልጅ |
| **ውጤቶች እና ሪዝልቶች** | የትምህርት ነጥቦች፣ GPA፣ በየቴርሙ የክፍል ደረጃ |
| **የውጤት ካርዶች** | በቴርም መጨረሻ የታተሙ የውጤት ካርዶች ለማውረድ |
| **ክፍያዎች (Fees & Payments)** | የሚገባ ጠቅላላ ክፍያ፣ የተከፈለ መጠን፣ ቀሪ ሂሳብ |
| **መልዕክቶች** | ከልጅዎ መምህራን ጋር የመግባቢያ ደብተር |
| **ማስታወቂያዎች** | የትምህርት ቤት ማስታወቂያዎች እና ክስተቶች |

## በልጆች መካከል መቀያየር

ከአንድ በላይ ልጅ ከተመዘገቡ፣ በዳሽቦርዱ አናት ላይ ያለውን **የልጅ መራጭ (child selector)** ይጠቀሙ። የልጅዎን ስም እና ክፍል የሚያሳየውን ተቆልቋይ ዝርዝር ጠቅ በማድረግ በልጆች መካከል በቅጽበት መቀያየር ይችላሉ።

> [!NOTE]
> አካውንትዎ የተገናኘው በምዝገባ ወቅት በትምህርት ቤቱ ሬጅስትራር ከልጆችዎ ጋር ነው። አንድ ልጅ በዳሽቦርድዎ ላይ ከጎደለ፣ ግንኙነቱን ለመጠየቅ የትምህርት ቤቱን ቢሮ ያነጋግሩ።

## መጀመር

1. YeneSchoolን በብራውዘርዎ ወይም በሞባይል መተግበሪያ ይክፈቱ እና በወላጅ ማስረጃዎ ይግቡ።
2. ዳሽቦርዱ በራስ-ሰር ይጫናል፣ የመጀመሪያውን የተገናኘ ልጅዎን ማጠቃለያ ያሳያል።
3. ወደ መገኘት፣ ውጤቶች፣ ክፍያዎች ወይም መልዕክቶች ለመሄድ የላይኛውን ምናሌ ወይም የጎን አሞሌ ይጠቀሙ።
4. ብዙ ልጆች ካሉዎት ወደ ሌላ ልጅ ለመቀያየር የልጁን ስም ተቆልቋይ ዝርዝር ይንኩ።
