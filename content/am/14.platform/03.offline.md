# የመስመር ውጭ (Offline) ሁነታ (PWA)

YeneSchool **ተራማጅ ድር መተግበሪያ (Progressive Web App - PWA)** ነው፣ ይህም ማለት የበይነመረብ ግንኙነትዎ ቀርፋፋ ወይም የማይገኝ ቢሆንም እንኳ ሊሰራ ይችላል ማለት ነው። ይህ በተለይ የግንኙነት አቅም ውስን በሆነባቸው የኢትዮጵያ አካባቢዎች ጠቃሚ ነው።

## YeneSchool ን እንደ መተግበሪያ መጫን

1. YeneSchool ን በሞባይል አሳሽዎ (Chrome ወይም Safari) ይክፈቱ።
2. ሲጠየቁ **Add to Home Screen (ወደ መነሻ ገጽ ያክሉ)** የሚለውን ይንኩ — ወይም ከአሳሹ ምናሌ የ**Install App (መተግበሪያ ጫን)** አማራጭን ይጠቀሙ።
3. የመተግበሪያው አዶ ልክ እንደ ተለምዷዊ (native) መተግበሪያ በመነሻ ገጽዎ ላይ ይታያል።
4. የመስመር ውጭ (offline) መዳረሻን ጨምሮ ፈጣን ልምድ ለማግኘት ከዚያ ይክፈቱት።

## ከመስመር ውጭ ምን ይሰራል

| ባህሪ | ከመስመር ውጭ ይገኛል |
|---|---|
| ቀደም ሲል የተጫኑ የመገኘት መዝገቦችን መመልከት | ✅ አዎ |
| የተማሪ መገኘት ምልክት ማድረግ (መምህራን) | ✅ አዎ |
| ለተማሪዎች ውጤት ማስገባት (መምህራን) | ✅ አዎ |
| የጊዜ ሰሌዳ (timetable) መመልከት | ✅ አዎ |
| የወረዱ ማስታወቂያዎችን ማንበብ | ✅ አዎ |
| ክፍያን በመስመር ላይ መክፈል | ❌ በይነመረብ ይጠይቃል |
| መልዕክቶችን መላክ ወይም መቀበል | ❌ በይነመረብ ይጠይቃል |
| አዲስ ማሳወቂያዎችን መጫን | ❌ በይነመረብ ይጠይቃል |
| የውጤት ካርዶችን ለመጀመሪያ ጊዜ መመልከት | ❌ በይነመረብ ይጠይቃል |

> [!NOTE]
> ከመስመር ውጭ ከመሆንዎ በፊት የተመለከቷቸው ውሂቦች በካሽ (cache) ውስጥ ይቀመጣሉ እና አሁንም ሊነበቡ ይችላሉ። አዲስ ውሂብ — ከመስመር ውጭ በነበሩበት ጊዜ የታተሙ ውጤቶችን የመሳሰለ — መልሰው ከተገናኙ በኋላ ብቻ ይታያል።

## ከመስመር ውጭ መሆንዎን እንዴት ማወቅ እንደሚቻል

YeneSchool የበይነመረብ ግንኙነት አለመኖሩን ሲያውቅ፣ በማያ ገጹ ላይ **"ከመስመር ውጭ ነዎት (You are offline)"** የሚል ባነር ይታያል። ግንኙነቱ ሲመለስ ባነሩ በራስ-ሰር ይጠፋል።

## ማመሳሰል (Sync) እንዴት ይሰራል

ግንኙነትዎ ሲመለስ፦

1. ከመስመር ውጭ የተደረጉ ማንኛቸውም የመገኘት ወይም የውጤት ግቤቶች በራስ-ሰር ከበስተመጋራ (background) ይሰቀላሉ (upload)።
2. ከአገልጋዩ (server) አዲስ ውሂብ (ማሳወቂያዎች፣ መልዕክቶች፣ የተሻሻሉ ውጤቶች) ይወርዳል።
3. የቅርብ ጊዜ መረጃን ለማሳየት መገናኛው (interface) ይታደሳል።

> [!IMPORTANT]
> ከተገናኙ በኋላ ወዲያውኑ መተግበሪያውን አይዝጉ። ከመውጣትዎ (log out) በፊት የበስተመጋራ ማመሳሰል እንዲጠናቀቅ ጥቂት ሰከንዶች ይፍቀዱ።
