# የፈተና ዝግጅት እና ውቅር

በትምህርት ቤትዎ ውስጥ ፈተናዎች እንዴት እንደሚሰሩ ያዋቅሩ — የውጤት መርሃግብሮች፣ የክፍል ምደባዎች እና የፈተና መርሐ ግብሮች።

## የውጤት መርሃግብሮች

YeneSchool ብዙ የውጤት መርሃግብሮችን ይደግፋል፦

| መርሃግብር | መግለጫ | ምሳሌ |
|--------|-------------|---------|
| **መቶኛ** | ከ100 ውስጥ የተገኘ ምልክት | 85/100 |
| **የፊደል ውጤት** | A፣ B፣ C፣ D፣ F | A (90-100)፣ B (80-89) |
| **GPA** | አማካይ የነጥብ ውጤት | 3.5 GPA |
| **ብጁ** | ለትምህርት ቤት የተለየ ውጤት አሰጣጥ | ብጁ ክልሎች እና መለያዎች |

1. ወደ **ቅንብሮች → የውጤት መርሃግብር** ይሂዱ
2. የውጤት መርሃግብር ይምረጡ ወይም ይፍጠሩ
3. የምልክት ክልሎችን እና ተጓዳኝ ውጤቶችን ይግለጹ
4. **አስቀምጥ** የሚለውን ይጫኑ

## የፈተና ክፍሎች

ለፈተና መቀመጫ ክፍሎችን ያዋቅሩ፦

1. በጎን አሞሌው ውስጥ ወደ **የፈተና ክፍሎች** ይሂዱ
2. ክፍሎችን ከአቅማቸው ጋር ያክሉ
3. ክፍሎችን ለፈተናዎች ይመድቡ
4. የመቀመጫ ገበታዎችን ያመንጩ

## የፈተና ቅንብሮች

| ቅንብር | መግለጫ |
|---------|-------------|
| **የፈተና ሁኔታ** | የጽሁፍ፣ የቃል፣ የተግባር ወይም የመስመር ላይ |
| **ፀረ-ማጭበርበር** | ለመስመር ላይ ፈተናዎች የመቆለፊያ አሳሽ አግብር |
| **የሰዓት ገደቦች** | በፈተና እና በጥያቄ የሰዓት ገደቦች |
| **በዘፈቀደ ማደራጀት** | ለመስመር ላይ ፈተናዎች የጥያቄ ቅደም ተከተልን በዘፈቀደ ማድረግ |
| **ማስገቢያ** | ሰዓቱ ሲያልቅ በራስ-ሰር ማስገባት |

## የመስመር ላይ ፈተናዎች

YeneSchool የመስመር ላይ ፈተናዎችን በሚከተሉት ይደግፋል፦

- ተማሪዎች እንዲዘጋጁ የልምምድ ፈተናዎች
- በራስ-ሰር ማስገቢያ ያላቸው የሰዓት የተገደቡ ግምገማዎች
- ለተጨባጭ ጥያቄዎች ራስ-ሰር ውጤት አሰጣጥ
- ለግላዊ መልሶች በእጅ ውጤት አሰጣጥ
- የቀጥታ ቁጥጥር እና ክትትል

> [!TIP]
> ከትክክለኛው ፈተና በፊት ተማሪዎች የመስመር ላይ የፈተና በይነገጽን እንዲለምዱ **የልምምድ ፈተናዎችን** ይጠቀሙ።
