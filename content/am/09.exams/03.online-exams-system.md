# የመስመር ላይ የኮምፒውተር ላይ የተመሰረተ የፈተና ስርዓት

**የYeneSchool የመስመር ላይ ፈተና ስርዓት** ለትምህርት ቤቶች አጠቃላይ የኮምፒውተር ላይ የተመሰረተ የፈተና (CBT) መድረክ ያቀርባል። መምህራን እና ዳይሬክተሮች ፈተናዎችን መፍጠር፣ በCSV በመቶዎች የሚቆጠሩ ጥያቄዎችን ማስገባት፣ በዘፈቀደ የጥያቄ ስብስቦችን ማዋቀር፣ የፀረ-ማጭበርበር መቆጣጠሪያዎችን መተግበር እና ወዲያውኑ የአፈጻጸም ትንታኔዎችን ማምረት ይችላሉ።

---

## 1. የሚደገፉ የጥያቄ አይነቶች

| የጥያቄ አይነት | ራስ-ሰር ውጤት አሰጣጥ | መግለጫ እና ቅርጸት |
| :--- | :---: | :--- |
| **ብዙ ምርጫ (MCQ)** | አዎ | ከ2 እስከ 5 አማራጮች ከአንድ ትክክለኛ መልስ ጋር። የምስል ማያያዣዎችን ይደግፋል። |
| **ብዙ መልስ** | አዎ | ከፊል ክሬዲት ወይም ትክክለኛ ተዛማጅ ውጤት ያላቸው ብዙ ትክክለኛ ምርጫዎች። |
| **እውነት / ሐሰት** | አዎ | የሁለትዮሽ ግምገማ መግለጫ። |
| **አጭር መልስ / ባዶ መሙላት** | አዎ | ከጉዳይ-ስሜት ገለል የሆነ እና ተመሳሳይ ቃል ተለዋዋጭነት ያለው የጽሁፍ ተዛማጅ። |
| **ድርሰት / ክፍት መጨረሻ** | በእጅ | የመምህር ሩብሪክ ውጤት የሚፈልግ ጽሁፍ ድርሰት ወይም የተሰቀለ ስዕላዊ መግለጫ። |

---

## 2. ጥያቄዎችን በጅምላ በCSV ማስገባት

መምህራን በExcel ወይም በGoogle Sheets ውስጥ ጥያቄዎችን በማዘጋጀት በሰከንዶች ውስጥ ማስገባት ይችላሉ፦

1. ይፋዊውን **YeneSchool የጥያቄ አብነት** (`.csv`) ያውርዱ።
2. መደበኛ ዓምዶቹን ይሙሉ፦

| ዓምድ | ምሳሌ እሴት | መግለጫ |
| :--- | :--- | :--- |
| `question_type` | `MCQ` | `MCQ`፣ `TRUE_FALSE`፣ `SHORT_ANSWER`፣ ወይም `ESSAY` |
| `question_text` | `What is the capital city of Ethiopia?` | የተሟላ የጥያቄ ጥያቄ (LaTeX ሂሳብ ይደግፋል)። |
| `option_a` | `Addis Ababa` | ምርጫ A |
| `option_b` | `Hawassa` | ምርጫ B |
| `option_c` | `Dire Dawa` | ምርጫ C |
| `option_d` | `Bahir Dar` | ምርጫ D |
| `correct_answer` | `A` | ተዛማጅ ቁልፍ ፊደል ወይም እውነት/ሐሰት እሴት። |
| `marks` | `2` | ለትክክለኛ መልስ የሚሰጡ ነጥቦች። |
| `explanation` | `Addis Ababa has been the capital since 1886.` | ከፈተና በኋላ በሚደረገው ግምገማ ለተማሪ ይታያል። |

3. በ**መምህር → የመስመር ላይ ፈተናዎች → የጥያቄ ባንክ** ውስጥ **CSV ስቀል** የሚለውን ይጫኑ።
4. የቅድመ-እይታ ማረጋገጫን ይገምግሙ፣ ማንኛውንም የቅርጸት ማስጠንቀቂያዎችን ይፍቱ እና **ወደ ጥያቄ ባንክ አስገባ** የሚለውን ይጫኑ።

---

## 3. የፈተና ደህንነት እና የፀረ-ማጭበርበር መቆጣጠሪያዎች

የመስመር ላይ ፈተናን ሲያትሙ የደህንነት ቅንብሮችን ያዋቅሩ፦

- **የጥያቄ እና የምርጫ በዘፈቀደ ማደራጀት፦** እያንዳንዱ ተማሪ ጥያቄዎችን በተለየ በዘፈቀደ ቅደም ተከተል ከተደባለቁ ምርጫዎች ጋር ይቀበላል።
- **የትር መቀየር መለየት፦** ተማሪ ከፈተና ትሩ ርቆ ከሄደ፣ ስርዓቱ የማስጠንቀቂያ ምልክት ይመዘግባል እና ተቆጣጣሪዎችን ያሳውቃል።
- **ሙሉ-ስክሪን ማስፈጸም፦** ፈተናው ጥብቅ የሙሉ-ስክሪን ሁነታ ውስጥ ይገባል እና የቀኝ-ጠቅታ ቅዳ/ለጥፍ አቋራጮችን ያሰናክላል።
- **የሰዓት ገደቦች እና ራስ-ሰር ማስገቢያ፦** ሰዓቱ 00:00 ሲደርስ መልሶችን በራስ-ሰር የሚቆልፍ እና የሚያስገባ ጥብቅ የመቁጠሪያ ሰዓት።
