# የአካዳሚክ አጠቃላይ እይታ

የአካዳሚክ አስተዳደር ሞጁል የYeneSchool የጀርባ አጥንት ነው። ከትምህርት ዓመታት እስከ ዕለታዊ የጊዜ ሰሌዳዎች ድረስ ሁሉንም ነገር ያደራጃል።

## የሞጁል ካርታ

| ባህሪ | መግለጫ |
|---------|-------------|
| **የትምህርት ዓመታት** | የትምህርት ዓመታትን እና ክፍለ ጊዜዎችን መፍጠር እና ማስተዳደር |
| **ክፍሎች እና ክፍለ ክፍሎች** | ተማሪዎችን በክፍሎች እና ክፍለ ክፍሎች ማደራጀት |
| **ትምህርቶች** | ትምህርቶችን መፍጠር እና መምህራንን መመደብ |
| **ትምህርቶች** | ትምህርቶችን ማቀድ እና ማቅረብ |
| **የጊዜ ሰሌዳዎች** | ሳምንታዊውን መርሐ ግብር መገንባት |
| **የትምህርት ጊዜ ሰዓቶች** | የትምህርት ጊዜ ቆይታዎችን እና የደወል መርሐ ግብሮችን ማዋቀር |
| **ፈተናዎች** | ፈተናዎችን መፍጠር እና ግምገማዎችን ማስተዳደር |
| **የውጤት መዝገብ** | የተማሪ ውጤቶችን ማስገባት እና ማስተዳደር |
| **የውጤት ካርዶች** | የክፍለ ጊዜ መጨረሻ የውጤት ካርዶችን ማመንጨት |
| **ዕድገት** | የዓመት መጨረሻ የክፍል ዕድገትን ማካሄድ |

## የትምህርት ዓመት የስራ ፍሰት

1. **የትምህርት ዓመት ፍጠር** — ዓመቱን፣ የክፍለ ጊዜ ቀናትን እና የቀን መቁጠሪያ አይነትን ይግለጹ
2. **ክፍለ ጊዜዎች አክሉ** — ዓመቱን ወደ ክፍለ ጊዜዎች ይከፋፍሉ
3. **ክፍሎች ፍጠሩ** — ክፍሎችን እና ክፍለ ክፍሎችን ያዘጋጁ
4. **ትምህርቶች መድቡ** — ትምህርቶችን ከመምህራን ጋር ለክፍሎች ያገናኙ
5. **የጊዜ ሰሌዳ ገንቡ** — ለእያንዳንዱ ክፍል የትምህርት ጊዜዎችን ይመድቡ
6. **ክፍለ ጊዜዎች አግብሩ** — ለመረጃ ቀረጻ ንቁውን ክፍለ ጊዜ ያዘጋጁ

## የኢትዮጵያ ቀን መቁጠሪያ ድጋፍ

YeneSchool ሁለቱንም **የኢትዮጵያ ቀን መቁጠሪያ (ኢ.ት.ዓመት)** እና **የጎርጎርያን ቀን መቁጠሪያ (ጎ.ዓመት)** ይደግፋል። እያንዳንዱ የትምህርት ዓመት ማንኛውንም የቀን መቁጠሪያ በገለልተኝነት መጠቀም ይችላል።

## ቁልፍ ጽንሰ-ሐሳቦች

- **ብዙ ክፍለ ጊዜ ድጋፍ** — እያንዳንዱ ዓመት ብዙ ክፍለ ጊዜዎች አሉት፤ በአንድ ጊዜ አንዱ ብቻ ንቁ ነው
- **በቅርንጫፍ የተገደበ መረጃ** — ሁሉም መረጃ ለመረጃ መገለል በቅርንጫፎች የተገደበ ነው
- **ብዙ ቋንቋ** — አማርኛን ጨምሮ 5 ቋንቋዎች ሙሉ ድጋፍ
- **መጀመሪያ ከመስመር ውጪ** — መገኘት እና ውጤቶች ከመስመር ውጪ ተመዝግበው ሊመሳሰሉ ይችላሉ

> [!TIP]
> መገኘትን ወይም ውጤቶችን ከመመዝገብዎ በፊት ሁልጊዜ ትክክለኛውን **ንቁ ክፍለ ጊዜ** ያዘጋጁ። መረጃው ለንቁ ክፍለ ጊዜ የተገደበ ነው።
