# የመማሪያ ክፍል ምልከታ እና የውጤት መስፈርቶች

የመምህሩን ውጤታማነት፣ የተማሪዎችን ተሳትፎ እና የክፍል አስተዳደርን ለመገምገም በዲጂታል የውጤት መስፈርቶች አማካኝነት የተዋቀሩ የመማሪያ ክፍል ምልከታዎችን ያካሂዱ።

---

## 1. ምልከታ ማስያዝ

1. ወደ **ሱፐርቫይዘር → ምልከታዎች** ይሂዱ።
2. **+ ምልከታ ያስይዙ** የሚለውን ይጫኑ።
3. **መምህሩን**፣ **ትምህርቱን / ሰዓቱን**፣ **የክፍል ሴክሽኑን** እና **ቀኑን** ይምረጡ።
4. የግምገማውን ዓይነት ይምረጡ፦ *መደበኛ የምዕራፍ ምልከታ፣ የአቻ ግምገማ፣ ወይም የአዲስ መምህር ማስተዋወቅ ምርመራ*።
5. መምህሩን በራስ-ሰር በኢሜይል እና በመተግበሪያ ውስጣዊ ማሳወቂያ ያሳውቁ።

---

## 2. መደበኛ የምልከታ የውጤት መስፈርት ልኬቶች

በምልከታው ወቅት፣ መምህሩን በመደበኛ የ4-ነጥብ ሚዛን (*1 = እርካታ የሌለው፣ 2 = በማደግ ላይ፣ 3 = ብቁ፣ 4 = ምሳሌነት ያለው*) ይገምግሙ፦

| የግምገማ ዘርፍ | ቁልፍ የምልከታ መመዘኛዎች |
| :--- | :--- |
| **1. ትምህርታዊ አቀራረብ** | ግልጽ ማብራሪያ፣ የትምህርት ዕውቀት ሙላት፣ የማስተማሪያ መርጃዎች / ጥቁር ሰሌዳ ውጤታማ አጠቃቀም፣ መረዳትን መፈተሽ። |
| **2. የተማሪ ተሳትፎ** | ንቁ የተማሪ ተሳትፎ፣ ሁሉን አካታች ጥያቄዎች፣ የቡድን ትብብር፣ ፍትሃዊ የተማሪ ተሳትፎ። |
| **3. የክፍል አስተዳደር** | የጊዜ አመዳደብ፣ በተግባራት መካከል ለስላሳ ሽግግር፣ ግልጽ የባህሪ ተስፋዎች፣ አዎንታዊ ግንኙነት። |
| **4. ግምገማ እና አስተያየት**| በክፍል ውስጥ ቀጣይነት ያለው ግምገማ፣ በተማሪ ስህተቶች ላይ ገንቢ አስተያየት፣ ግልጽ የቤት ሥራ መመሪያዎች። |

---

## 3. ከምልከታ በኋላ ያለው ስብሰባ እና ማረጋገጫ

1. አጠቃላይ የክብደት ተጓዳኝ የምልከታ ውጤትን ያስሉ።
2. **ቁልፍ ጠንካራ ጎኖችን** እና **የመሻሻያ ዘርፎችን** ይጻፉ።
3. ለቀጣዩ የምልከታ ዑደት ከ1–3 ተጨባጭ **የተግባር ግቦችን** ያዘጋጁ።
4. ግኝቶችን ለመወያየት ከመምህሩ ጋር የ10 ደቂቃ የግምገማ ስብሰባ ያስይዙ።
5. ሁለቱም ሱፐርቫይዘሩ እና መምህሩ የተጠናቀቀውን የግምገማ መዝገብ በዲጂታል ይፈርማሉ።
