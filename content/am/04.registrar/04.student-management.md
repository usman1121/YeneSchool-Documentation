# የተማሪ አስተዳደር

**የተማሪ ዝርዝሩ** በትምህርት ቤቱ ውስጥ የትኛውንም የተማሪ መዝገብ ለማግኘት፣ ለመገምገም እና ለማዘመን ማዕከላዊ መገናኛ ነው።

## የተማሪ ዝርዝሩን መድረስ

ከሬጅስትራር ዳሽቦርድ **ተማሪዎችን ያቀናብሩ**ን ጠቅ ያድርጉ። ይህ ሙሉውን የተማሪ ዝርዝር በ`/list/students` ይከፍታል።

## መፈለግ እና ማጣራት

ተማሪዎችን ለማግኘት ከላይ ያለውን የፍለጋ አሞሌ ይጠቀሙ፦

- ሙሉ ስም ወይም የስም ክፍል
- የተማሪ ኮድ (የመግቢያ ቁጥር)
- የኢሜይል አድራሻ
- የስልክ ቁጥር

በተጨማሪም ባሉት ተቆልቋይ ዝርዝሮች በመጠቀም ዝርዝሩን ማጣራት ይችላሉ፦

| ማጣሪያ | አማራጮች |
|---|---|
| የትምህርት ዘመን | ከሁሉም ከተዋቀሩ ዓመታት ይምረጡ |
| ክፍል / ትምህርት ክፍል | በተወሰነ የክፍል ደረጃ ያጣሩ |
| ሴክሽን | ወደ አንድ የተወሰነ ሴክሽን ያጥብቡ |
| የምዝገባ ሁኔታ | ንቁ፣ በመጠባበቅ ላይ፣ ጸድቋል፣ ውድቅ ተደርጓል |
| ፆታ | ወንድ / ሴት |

> [!TIP]
> ለአንድ የተወሰነ ክፍል ማን እንዳለ በትክክል ለማየት የክፍል ማጣሪያን ከሴክሽን ማጣሪያ ጋር ያጣምሩ፣ ይህ የክፍል ዝርዝሮችን ወይም የመገኘት ወረቀቶችን ሲያዘጋጁ ጠቃሚ ነው።

## የተማሪ መገለጫ ማርትዕ

1. የማንኛውም ተማሪ ስም ወይም ረድፍ ጠቅ በማድረግ የ**መገለጫ ገጻቸውን** ይክፈቱ።
2. ወደ የማርትዕ ሁነታ ለመግባት **አርትዕ**ን (የእርሳስ አዶ) ጠቅ ያድርጉ።
3. ማዘመን ይችላሉ፦
   - የግል ዝርዝሮች — ስም፣ የትውልድ ቀን፣ ፆታ፣ ስልክ፣ ኢሜይል
   - የፋይዳ ቁጥር (FAN)
   - የአሳዳጊ መረጃ — የወላጅ ስም፣ ስልክ፣ ዝምድና
   - የመገለጫ ፎቶ — አዲስ ፎቶ ይስቀሉ ወይም ያለውን ይተኩ
4. ለውጦችን ለመተግበር **አስቀምጥ**ን ጠቅ ያድርጉ። የተማሪው የመግቢያ መለያ በራስ-ሰር ይዘመናል።

> [!WARNING]
> የተማሪውን የስልክ ቁጥር መቀየር የመግቢያ ተጠቃሚ ስማቸውን ይቀይራል። ተማሪውን ስለ አዲሱ የመግቢያ ዝርዝር ያሳውቁ።

## የተማሪ ታሪክ መመልከት

በYeneSchool ውስጥ የተሟላ ታሪካቸውን ለማየት በተማሪ መገለጫ ላይ **እይ**ን ጠቅ ያድርጉ፦

| ትር | የሚያዩት |
|---|---|
| መገለጫ | የግል ዝርዝሮች፣ ፎቶ፣ የአሳዳጊ መረጃ፣ የተማሪ ኮድ |
| መገኘት | በሁሉም የትምህርት ወቅቶች ውስጥ የቀን ተቀን የመገኘት መዝገቦች |
| ውጤቶች | በየወቅቱ የትምህርት ውጤት ምልክቶች እና የውጤት ካርድ ማጠቃለያዎች |
| ክፍያዎች | የክፍያ ደረሰኞች፣ የክፍያ ታሪክ፣ የቀረ ሂሳብ |
| ሰነዶች | የተሰቀሉ ሰነዶች — ፎቶዎች፣ የውጤት ግልባጮች፣ የምስክር ወረቀቶች |
| ምዝገባ | የአሁኑ ክፍል፣ ሴክሽን እና የምዝገባ ሁኔታ በየዓመቱ |

## ሰነዶችን ማስተዳደር

1. የተማሪውን መገለጫ ይክፈቱ እና ወደ **ሰነዶች** ትር ይሂዱ።
2. እንደ የልደት የምስክር ወረቀት፣ የቀድሞ ትምህርት ቤት የውጤት ግልባጭ ወይም ፎቶዎች ያሉ ፋይሎችን ለማያያዝ **ሰነድ ስቀል**ን ጠቅ ያድርጉ።
3. እያንዳንዱ ሰነድ የአይነት መለያ አለው (ለምሳሌ `PHOTO`, `TRANSCRIPT`, `CERTIFICATE`)፣ ስለዚህ በኋላ ለመፈለግ እና ለማጣራት ቀላል ነው።

> [!NOTE]
> እዚህ የተሰቀሉ ሰነዶች አንዴ ከታተሙ በኋላ ለተማሪው እና ለተገናኘው ወላጅ/አሳዳጊ እንዲሁ ይታያሉ።
