# ካታሎግ እና ምድቦችን ማስተዳደር

በሚገባ የተዋቀረ ካታሎግ ትክክለኛ የትምህርት ቤት የእቃ ክምችት ክትትል መሠረት ነው።

---

## 1. የእቃ ምድቦችን መፍጠር

1. በጎን አሞሌው ውስጥ ወደ **እቃ ክምችት → ምድቦች** ይሂዱ።
2. **+ ምድብ አክል** የሚለውን ይጫኑ።
3. የምድብ ዝርዝሮችን ያስገቡ፦
   - **የምድብ ስም፦** (ለምሳሌ *የሳይንስ ቤተ ሙከራ ኬሚካሎች፣ የሂሳብ መማሪያ መጽሐፎች፣ የተማሪ ዩኒፎርሞች*)።
   - **የምድብ ኮድ / ቅድመ-ቅጥያ፦** (ለምሳሌ *LAB፣ TXT-MATH፣ UNI*)።
   - **መግለጫ፦** በዚህ ምድብ ውስጥ ያሉ እቃዎች አጭር ወሰን።
4. **ምድብ አስቀምጥ** የሚለውን ይጫኑ።

---

## 2. አዲስ የእቃ ክምችት እቃዎችን መመዝገብ

1. ወደ **እቃ ክምችት → የእቃ ካታሎግ** ይሂዱ።
2. **+ እቃ መዝግብ** የሚለውን ይጫኑ።
3. የእቃውን ዝርዝሮች ይሙሉ፦

| የመስክ ስም | አይነት / ቅርጸት | ዓላማ እና ምሳሌ |
| :--- | :--- | :--- |
| **የእቃ ስም** | ጽሁፍ | የተለየ ስም (ለምሳሌ *የ9ኛ ክፍል ባዮሎጂ መማሪያ መጽሐፍ 2016 እትም*)። |
| **የእቃ SKU / ኮድ** | ፊደል-ቁጥር | ልዩ የእቃ ክምችት መለያ (ለምሳሌ *TXT-BIO-09*)። |
| **ምድብ** | የተቆልቋይ ዝርዝር | ከተፈጠሩ ምድቦች ይምረጡ። |
| **የመለኪያ አሃድ** | የተቆልቋይ ዝርዝር | ቁርጥራጮች፣ ሳጥኖች፣ ስብስቦች፣ ሊትሮች፣ ታሽዎች፣ ጥንዶች። |
| **የመጀመሪያ ብዛት** | ቁጥር | በመደብር ውስጥ ያለ አሁኑ አካላዊ ቆጠራ። |
| **የአሃድ የግዢ ወጪ** | ገንዘብ (ብር) | ለሚዛን ግምት በአንድ አሃድ ወጪ። |
| **የድጋሚ ትዕዛዝ ገደብ** | ቁጥር | የማንቂያ ማስጠንቀቂያ ከመስጠቱ በፊት ዝቅተኛው ቆጠራ (ለምሳሌ *15 ታሽዎች*)። |
| **የማከማቻ ቦታ** | ጽሁፍ | የክምችት ክፍል መደርደሪያ / ሳጥን ቦታ (ለምሳሌ *መደርደሪያ B-3*)። |

4. **እቃ አስቀምጥ** የሚለውን ይጫኑ። እቃው ለክምችት ግብይቶች እና ጥያቄዎች ወዲያውኑ ይገኛል።
