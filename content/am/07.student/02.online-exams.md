# የመስመር ላይ ፈተና ፖርታል

**የYeneSchool የመስመር ላይ ፈተና ፖርታል** ተማሪዎች ደህንነቱ የተጠበቀ፣ በጊዜ የተገደቡ በኮምፒውተር ላይ የተመሰረቱ ግምገማዎችን፣ መካከለኛ ፈተናዎችን እና የልምምድ ጥያቄዎችን በቀጥታ ከብራውዘራቸው ወይም ከሞባይል መሳሪያቸው እንዲያጠናቅቁ ያስችላል።

---

## 1. ፈተና ከመጀመር በፊት

1. ከተማሪው የጎን አሞሌ ውስጥ ወደ **የመስመር ላይ ፈተናዎች** ይሂዱ።
2. የ**ተገኙ ፈተናዎች** ዝርዝርን ይገምግሙ፣ በመጥቀስ፦
   - **የትምህርት ዓይነት እና ርዕስ፦** (ለምሳሌ፣ *የ10ኛ ክፍል ፊዚክስ መካከለኛ ፈተና*)
   - **የተቀጠረ መስኮት፦** የመጀመሪያ ሰዓት እና የመዘጋት (expiration) ቀነ-ገደብ።
   - **ቆይታ፦** የተፈቀደ ጊዜ በደቂቃ (ለምሳሌ 60 ደቂቃ)።
   - **ጠቅላላ ጥያቄዎች እና የማለፊያ ነጥብ፦** ሊገኝ የሚችል ጠቅላላ ነጥብ እና ዝቅተኛው የማለፊያ ነጥብ።
3. የመሳሪያዎ ባትሪ የተረጋጋ መሆኑን ያረጋግጡ እና **ፈተና ይጀምሩ (Start Exam)** ን ይጫኑ።
4. የፈተና መመሪያዎችን እና የክብር ቃል መስኮቱን (honor pledge modal) ያንብቡ፣ ከዚያ ወደ ፈተናው አካባቢ ለመግባት ያረጋግጡ።

---

## 2. የፈተና በይነገጽ እና ባህሪያት

| የበይነገጽ አካል | መግለጫ እና ተግባር |
| :--- | :--- |
| **የቁጥር ሰዓት ቆጣሪ (Countdown Timer)** | በላይኛው ራዕስ ላይ የቀሩትን ደቂቃዎች እና ሰከንዶች የሚያሳይ ከፍተኛ ንፅፅር ያለው ሰዓት። ቀለሙ በ5 ደቂቃ ላይ ወደ አምበር እና በ1 ደቂቃ ላይ ወደ ቀይ ይቀየራል። |
| **የጥያቄ ዳሰሻ ፓሌት** | እያንዳንዱን ጥያቄ የሚወክል የቁጥር አዝራሮች ፍርግርግ፦ ግራጫ (ያልተመለሰ)፣ ሰማያዊ (የተመለሰ)፣ ቢጫ ባንዲራ (ለግምገማ ምልክት የተደረገ)። |
| **የጥያቄ እይታ** | የጥያቄውን ጽሑፍ፣ ደጋፊ ሥዕላዊ መግለጫዎች/ምስሎች እና ምርጫዎች (ብዙ ምርጫ፣ እውነት/ሐሰት ወይም አጭር መልስ) ያሳያል። |
| **የጥያቄ ባንዲራ አዝራር** | አስቸጋሪ ጥያቄዎችን ምልክት እንዲያደርጉ ያስችልዎታል፣ ስለዚህ ከማስገባቱ በፊት በቀላሉ መመለስ ይችላሉ። |
| **በራስ-ሰር የማስቀመጥ አመልካች** | እያንዳንዱ መልስ ወዲያውኑ ወደ ሰርቨር እና ወደ አካባቢያዊ የመሳሪያ ማህደረ ትውስታ መመዝገቡን የሚያረጋግጥ አረንጓዴ ምልክት ነው። |

---

## 3. ፈተናውን ማስገባት

1. ሁሉንም ጥያቄዎች ከመለሱ በኋላ፣ ምልክት ያደረጉባቸውን እቃዎች በጥያቄ ፓሌት በኩል ይገምግሙ።
2. ከታች በቀኝ ጥግ ያለውን አረንጓዴ **ፈተና ያስገቡ (Submit Exam)** አዝራር ይጫኑ።
3. የማረጋገጫ ዳያሎግ የተመለሱ ጠቅላላ ጥያቄዎችን እና የቀረውን ጊዜ ያሳያል።
4. **የመጨረሻ መልሶችን ያረጋግጡ እና ያስገቡ** ን ይጫኑ።

> [!NOTE]
> ፈተና በሚወስዱበት ጊዜ ሰዓት ቆጣሪው ካለቀ፣ ስርዓቱ የአሁኑን ምርጫዎችዎን በራስ-ሰር ያስቀምጣል እና ፈተናውን በእርስዎ ምትክ ያስገባል፣ ስለዚህ የተመለሱ ጥያቄዎች አይጠፉም።

---

## 4. የፈተና ውጤቶችን መመልከት

- **ዓላማ ያላቸው ፈተናዎች (መልቲፕል ቾይስ እና እውነት/ሐሰት)፦** አንዴ ከገቡ፣ ውጤትዎ እና መቶኛዎ ወዲያውኑ ይሰላል። አስተማሪው የፈተና በኋላ ግምገማን ካነቃ፣ ትክክለኛ መልሶችን እና የመምህሩን ማብራሪያዎች መገምገም ይችላሉ።
- **ግላዊ ፈተናዎች (አጭር መልስ / ድርሰቶች)፦** ውጤቶቹ የሚታተሙት መምህሩ ክፍት መልሶችን ካስተካከለ በኋላ ነው። የመጨረሻው ውጤት ሲለጠፍ በመተግበሪያው ውስጥ ማሳወቂያ ይደርስዎታል።
