# Communication Overview

The Communication module keeps everyone connected — teachers, students, parents, and administrators. YeneSchool supports multiple notification channels to ensure important messages are never missed.

## Module Map

| Feature | Description |
|---------|-------------|
| **Announcements** | School-wide and targeted announcements |
| **Messaging** | Direct messages between users |
| **Communication Book** | Threaded conversations between teachers and parents |
| **Notification Preferences** | Manage how you receive notifications |

## Channels

| Channel | Description | Best For |
|---------|-------------|----------|
| **In-App** | Notification within the app | General alerts |
| **Push** | Mobile push notification | Urgent updates |
| **Email** | Email delivery | Formal announcements |
| **SMS** | Text message | Quick reminders |
| **Telegram** | Telegram message | Modern communication |

## Announcement Types

- **School-Wide** — Sent to all users
- **Role-Based** — Sent to a specific role (teachers, parents, students)
- **Class-Specific** — Sent to a specific class
- **Individual** — Sent to a specific user

## Communication Book

The communication book provides a thread-based conversation system between teachers, students, and parents. All messages are archived and searchable.

> [!TIP]
> Enable push notifications so parents receive instant alerts — no need to log in every time to check for updates about their child.
