# Backup & Maintenance

Regular backups and maintenance are essential for keeping your YeneSchool data safe and the system running smoothly.

## Automated Backups

### Database Backups

PostgreSQL databases should be backed up regularly:

```bash
# Manual backup
pg_dump -h localhost -U user -d sms > backup_$(date +%Y%m%d).sql

# Automated daily backup
# Add to crontab: 0 2 * * * pg_dump -h localhost -U user -d sms > /backups/sms_$(date +\%Y\%m\%d).sql
```

### Configuration Backups

Back up your configuration files:

```bash
# Back up .env files, docker-compose.yml, and nginx config
tar -czf config_backup_$(date +%Y%m%d).tar.gz .env docker-compose.yml nginx/
```

## Maintenance Tasks

| Task | Frequency | Command |
|------|-----------|---------|
| **Database backup** | Daily | `pg_dump` |
| **Clear cache** | Weekly | `npm run build` |
| **Update dependencies** | Monthly | `npm update` |
| **Prune old backups** | Monthly | Delete backups older than 30 days |
| **Review logs** | Weekly | Check application logs |
| **Update SSL certificates** | Before expiry | Renew with your certificate provider |

## Monitoring

Monitor the health of your YeneSchool instance:

- **Frontend** — Response time and error rate
- **Backend API** — Response time, database connections
- **PostgreSQL** — Disk usage, query performance
- **Redis** — Memory usage, connection count
- **BullMQ Queues** — Job processing status

## Log Management

YeneSchool generates logs for all operations. Configure log rotation:

```bash
# Add logrotate configuration
/etc/logrotate.d/yeneschool
```

## Disaster Recovery

In case of data loss:

1. Restore the latest database backup
2. Restore configuration files
3. Restart all services
4. Verify data integrity
5. Notify users if needed

> [!WARNING]
> Test your backups regularly by restoring them to a test environment. Untested backups are not reliable backups.
