# Classes & Sections

Classes and sections organize students into groups for teaching, attendance, and grading. Each class can have multiple sections, and each section can have subject assignments.

## Creating Classes

1. Navigate to **Class Management** in the sidebar
2. Click **Create Class**
3. Set the class name (e.g., "Grade 5", "Grade 8", "KG 2")
4. Select the academic year the class belongs to
5. Click **Save**

## Adding Sections

Sections split a class into smaller groups (e.g., "Grade 5 Section A", "Grade 5 Section B"):

1. Open a class from the list
2. Click **Add Section**
3. Set the section name (e.g., "Section A")
4. Assign a class teacher
5. Click **Save**

## Subject Assignments

Assign subjects to classes for teaching:

1. Open a class or section
2. Click **Manage Subjects**
3. Add subjects and assign teachers to each subject
4. Set the number of periods per week for each subject
5. Click **Save**

## Class Management Features

| Feature | Description |
|---------|-------------|
| **Class Creation** | Create classes with any name or grade level |
| **Section Splitting** | Split classes into multiple sections |
| **Subject Assignment** | Assign subjects to classes with teachers |
| **Period Allocation** | Set how many periods per week each subject gets |
| **Class Teachers** | Assign a teacher as the class teacher |
| **Capacity Limits** | Set maximum student capacity per section |

> [!TIP]
> Use the **Class-Subject** page to see all subject assignments across classes at a glance.
