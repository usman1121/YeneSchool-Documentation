# Academic Overview

The Academic Management module is the backbone of YeneSchool. It organizes everything from academic years to daily timetables.

## Module Map

| Feature | Description |
|---------|-------------|
| **Academic Years** | Create and manage academic years and terms |
| **Classes & Sections** | Organize students into classes and sections |
| **Subjects** | Create subjects and assign teachers |
| **Lessons** | Plan and deliver lessons |
| **Timetables** | Build the weekly schedule |
| **Period Times** | Configure period durations and bell schedules |
| **Examinations** | Create exams and manage assessments |
| **Gradebook** | Enter and manage student grades |
| **Report Cards** | Generate end-of-term report cards |
| **Promotion** | Process end-of-year grade promotions |

## Academic Year Workflow

1. **Create Academic Year** — Define the year, term dates, and calendar type
2. **Add Terms** — Split the year into terms
3. **Create Classes** — Set up classes and sections
4. **Assign Subjects** — Link subjects to classes with teachers
5. **Build Timetable** — Schedule periods for each class
6. **Activate Terms** — Set the active term for data recording

## Ethiopian Calendar Support

YeneSchool supports both the **Ethiopian Calendar (EC)** and **Gregorian Calendar (GC)**. Each academic year can use either calendar independently.

## Key Concepts

- **Multi-Term Support** — Each year has multiple terms; only one is active at a time
- **Per-Branch Data** — All data is scoped to branches for data isolation
- **Multi-Language** — Full support for 5 languages including Amharic
- **Offline First** — Attendance and grades can be recorded offline and synced

> [!TIP]
> Always set the correct **Active Term** before recording attendance or grades. Data is scoped to the active term.
