# Overdue Fee Reports

The **Outstanding Balances** section of the Finance dashboard functions as your live overdue report. It shows every student with an unpaid or partially paid fee balance, and lets you filter, export, and send reminders.

## Viewing Outstanding Fees

1. On the Finance dashboard, scroll down to the **Outstanding Balances** tab.
2. Use the **Academic Year** and **Term** dropdowns at the top of the page to filter the period you want to review.
3. The table displays each student's name, grade, fee type, total fee, amount paid, remaining balance, and current status (Unpaid / Partial / Paid).

## Filtering the Report

- **Search by name or grade** — type in the search box above the table to narrow results.
- **Filter by status** — use the status dropdown to show only *Unpaid*, only *Partial*, or all statuses.

> [!TIP]
> To see only one grade's overdue list, type the grade number (e.g., *Grade 9*) in the search box.

## Exporting to CSV

1. Apply any filters you need (status, search term).
2. Navigate to **Finance → Reports** from the sidebar.
3. On the Reports page, select **Outstanding Balances Report**.
4. Choose the academic year and term, then click **Export CSV**.
5. The CSV file downloads to your computer with columns: Student Name, Grade, Section, Fee Type, Total, Paid, Balance, Status.

> [!NOTE]
> The CSV export respects whatever filters you have active, so filter first before exporting if you only need a subset.

## Sending SMS Reminders

1. On the **Outstanding Balances** tab, select the students you want to remind by checking the checkboxes next to their names (or use **Select All** for the current page).
2. Click the **Send Reminders** button that appears when students are selected.
3. Confirm the action in the dialog. YeneSchool sends an automated SMS to each selected student's registered parent/guardian phone number.
4. A confirmation toast shows how many messages were sent successfully.

> [!WARNING]
> SMS reminders are sent immediately. Make sure parents' phone numbers are up to date in the student profiles before sending. Confirm the list carefully — you cannot unsend messages.

> [!IMPORTANT]
> SMS sending requires the school's SMS gateway to be configured by the School Director. If the **Send Reminders** button is greyed out, contact your administrator to enable the SMS integration.
