# Administration Overview

The Administration module gives school owners and super admins full control over the YeneSchool platform — managing branches, users, settings, and subscriptions.

## Module Map

| Feature | Description |
|---------|-------------|
| **Multi-Branch** | Manage multiple campuses with branch directors |
| **Platform Settings** | School settings, calendar, academic year |
| **User Management** | Manage all user accounts and roles |
| **RBAC** | Role-based access control with 10 roles |
| **Subscription** | Plan management and billing |
| **Audit Logs** | Track all system actions |

## Administration Roles

| Role | Access Level |
|------|-------------|
| **Super Admin** | Full system access, all schools |
| **School Owner** | School management, branch creation |
| **Director** | Academic management, branch-specific data |
| **Registrar** | Student management, enrollment |

## Key Administration Tasks

1. **Create Schools** — Set up new schools in the system
2. **Create Branches** — Add campuses to existing schools
3. **Assign Branch Directors** — Give directors access to specific branches
4. **Configure Settings** — Set school name, calendar, academic year
5. **Manage Users** — Create, edit, deactivate user accounts
6. **Configure RBAC** — Set permissions for each role
7. **Manage Subscriptions** — Handle billing and plan changes

## Branch Management Features

- **Campus Creation** — Add unlimited branches per school
- **Branch Directors** — Dedicated directors per branch
- **Per-Branch Data** — All data scoped to branches
- **Branch Switching** — Quick switch between branches
- **Branch-Aware Dashboards** — Data filtered by selected branch

> [!TIP]
> Use the **branch switcher** in the header to quickly toggle between branches. All data updates instantly.
