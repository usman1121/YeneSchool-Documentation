# Multi-Branch Management

YeneSchool supports **multi-campus** operations, allowing a single school to have multiple branches with independent data scoping and dedicated branch directors.

## Creating Branches

1. Navigate to **Schools → Branches** in the sidebar
2. Click **Create Branch**
3. Set the branch details:
   - **Branch Name** — e.g., "Main Campus", "East Campus"
   - **Address** — Physical address of the branch
   - **Phone** — Contact phone number
   - **Branch Director** — Assign a director for this branch
4. Click **Save**

## Branch Directors

Each branch can have its own director with branch-specific permissions:

1. Go to **Staff → Branch Directors**
2. Assign a user as branch director
3. Select which branch(es) they manage
4. Set their permissions (view-only or full management)

## Per-Branch Data Scoping

All data is scoped to branches:

| Data Type | Branch Scoping |
|-----------|----------------|
| **Students** | Enrolled in a specific branch |
| **Teachers** | Assigned to a specific branch |
| **Classes** | Belong to a branch |
| **Attendance** | Recorded per branch |
| **Finance** | Fees scoped to branch |
| **Dashboards** | Show branch-specific data |

## Switching Between Branches

School owners and super admins can switch between branches:

1. Click the **branch switcher** in the header
2. Select the branch to view
3. All data updates to show the selected branch

> [!TIP]
> Branch directors can only see and manage data for their assigned branch. They cannot access data from other branches.
