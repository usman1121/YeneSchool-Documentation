# School Owner Guide

As a School Owner, you have full control over your YeneSchool instance — from managing branches and subscriptions to configuring platform-wide settings.

## What You Can Do

| Feature | Description |
|---------|-------------|
| **School Management** | Create and manage schools |
| **Branch Management** | Add and manage multiple campuses |
| **Subscription** | Manage billing and plans |
| **Platform Settings** | Configure calendar, language, and preferences |
| **User Management** | Create and manage all user accounts |
| **Audit Logs** | Track all system actions |
| **Backup** | Manage automated backups |

## Getting Started as a School Owner

1. Log in to the **School Owner Dashboard**
2. Navigate to **Settings → School Settings**
3. Configure your school name, address, and calendar type
4. Create academic years and terms
5. Set up your first branch
6. Invite and assign branch directors
7. Enroll students and assign teachers

## Managing Branches

1. Navigate to **Schools → Branches**
2. Click **Create Branch**
3. Set the branch name, address, and director
4. All data is scoped to the branch

## Subscription Management

1. Navigate to **Settings → Subscription**
2. View current plan and usage
3. Upgrade or downgrade plans
4. Manage payment methods

> [TIP]
> Branch directors can only see and manage data for their assigned branch. You can switch between branches using the branch switcher in the header.
