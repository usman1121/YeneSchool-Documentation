# Exam Setup & Configuration

Configure how exams work across your school — grading schemes, room assignments, and exam schedules.

## Grading Schemes

YeneSchool supports multiple grading schemes:

| Scheme | Description | Example |
|--------|-------------|---------|
| **Percentage** | Marks out of 100 | 85/100 |
| **Letter Grade** | A, B, C, D, F | A (90-100), B (80-89) |
| **GPA** | Grade Point Average | 3.5 GPA |
| **Custom** | School-specific grading | Custom ranges and labels |

1. Navigate to **Settings → Grading Scheme**
2. Select or create a grading scheme
3. Define the mark ranges and corresponding grades
4. Click **Save**

## Exam Rooms

Configure rooms for exam seating:

1. Navigate to **Exam Rooms** in the sidebar
2. Add rooms with their capacity
3. Assign rooms to exams
4. Generate seating charts

## Exam Settings

| Setting | Description |
|---------|-------------|
| **Exam Mode** | Written, Oral, Practical, or Online |
| **Anti-cheat** | Enable lockdown browser for online exams |
| **Time Limits** | Per-exam and per-question time limits |
| **Randomization** | Randomize question order for online exams |
| **Submission** | Auto-submit when time expires |

## Online Examinations

YeneSchool supports online examinations with:

- Practice exams for students to prepare
- Timed assessments with auto-submit
- Auto-grading for objective questions
- Manual grading for subjective answers
- Live proctoring and monitoring

> [!TIP]
> Use **Practice Exams** to let students familiarize themselves with the online exam interface before the real exam.
