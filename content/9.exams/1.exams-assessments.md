# Examinations & Assessments

YeneSchool supports both formal examinations and continuous assessments. Teachers can create exams, enter marks, and generate grading reports — all managed through the examination module.

## Creating Exams

1. Navigate to **Assessments** in the sidebar
2. Click **Create Exam**
3. Set the exam details:
   - **Exam Name** — e.g., "Midterm Exam", "Final Exam"
   - **Class** — Which class the exam is for
   - **Subject** — Which subject is being examined
   - **Date** — Exam date and time
   - **Maximum Marks** — Total possible marks
   - **Duration** — How long the exam lasts
4. Click **Save**

## Mark Entry

Teachers enter marks for each student:

1. Open the exam from the list
2. Click **Enter Marks**
3. Enter marks for each student (0 to max marks)
4. Add comments or feedback if needed
5. Click **Submit**

## Exam Workflow

| Stage | Description |
|-------|-------------|
| **Scheduled** | Exam is planned but not yet taken |
| **In Progress** | Students are taking the exam |
| **Grading** | Teachers are entering marks |
| **Published** | Marks are visible to students and parents |
| **Archived** | Final record, read-only |

## Continuous Assessment

Beyond exams, teachers can create continuous assessment tasks:

1. Create an assessment from the **Assessments** page
2. Set it as **Continuous Assessment** type
3. Students complete tasks throughout the term
4. Teachers enter marks as work is submitted

## Exam Seating

For large exams, configure seating arrangements:

1. Open the exam
2. Click **Seating Plan**
3. Drag students to seats in the classroom layout
4. Print the seating chart

> [!NOTE]
> The **Director Dashboard** shows upcoming exams in the KPI cards. Click on "Upcoming Exams" to see all scheduled exams at a glance.
