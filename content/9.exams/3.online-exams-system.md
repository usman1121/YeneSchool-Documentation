# Online Computer-Based Testing System

The **YeneSchool Online Examination System** provides schools with a comprehensive Computer-Based Testing (CBT) platform. Teachers and directors can author exams, import hundreds of questions via CSV, configure randomized question pools, enforce anti-cheating controls, and produce instant performance analytics.

---

## 1. Supported Question Types

| Question Type | Automated Grading | Description & Format |
| :--- | :---: | :--- |
| **Multiple Choice (MCQ)** | Yes | 2 to 5 option choices with single correct answer. Supports image attachments. |
| **Multiple Response** | Yes | Multiple correct choices with partial credit or exact match scoring. |
| **True / False** | Yes | Binary evaluation statement. |
| **Short Answer / Fill-in-Blank** | Yes | Text matching with case-insensitive and synonym flexibility. |
| **Essay / Open-Ended** | Manual | Written essay or uploaded diagram requiring teacher rubric scoring. |

## 2. Bulk Importing Questions via CSV

Teachers can draft questions in Excel or Google Sheets and import them in seconds:

1. Download the official **YeneSchool Question Template** (`.csv`).
2. Populate the standard columns:

| Column | Example Value | Description |
| :--- | :--- | :--- |
| `question_type` | `MCQ` | `MCQ`, `TRUE_FALSE`, `SHORT_ANSWER`, or `ESSAY` |
| `question_text` | `What is the capital city of Ethiopia?` | Full question prompt (supports LaTeX math). |
| `option_a` | `Addis Ababa` | Choice A |
| `option_b` | `Hawassa` | Choice B |
| `option_c` | `Dire Dawa` | Choice C |
| `option_d` | `Bahir Dar` | Choice D |
| `correct_answer` | `A` | Matching key letter or True/False value. |
| `marks` | `2` | Points awarded for correct answer. |
| `explanation` | `Addis Ababa has been the capital since 1886.` | Displayed to student in post-exam review. |

3. In **Teacher → Online Exams → Question Bank**, click **Upload CSV**.
4. Review preview validation, resolve any formatting flags, and click **Import to Question Bank**.

## 3. Exam Security & Anti-Cheating Controls

When publishing an online examination, configure security settings:

- **Question & Choice Randomization:** Every student receives questions in a distinct randomized sequence with shuffled choices.
- **Tab Switching Detection:** If a student navigates away from the exam tab, the system records a strike warning and notifies proctors.
- **Full-Screen Enforcement:** Exam enters strict full-screen mode and disables right-click copy/paste shortcuts.
- **Time Limits & Auto-Submit:** Strict countdown clock that automatically locks and submits answers when time reaches 00:00.
