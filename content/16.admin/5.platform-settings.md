# Platform Settings

Configure all aspects of your YeneSchool platform — school settings, user management, subscriptions, and platform-wide preferences.

## School Settings

Configure your school's core settings:

1. Navigate to **Settings → School Settings**
2. Set the following:
   - **School Name** — Display name for the school
   - **Calendar Type** — Ethiopian Calendar (EC) or Gregorian Calendar (GC)
   - **Academic Year** — Current active academic year
   - **Active Term** — Current active term
   - **School Address** — Physical address
   - **Phone & Email** — Contact information
3. Click **Save**

## User Management

Manage all user accounts:

1. Navigate to **Staff** or **Users** in the sidebar
2. View all registered users
3. Filter by role, branch, or status
4. Edit user details, reset passwords, or deactivate accounts

## Roles & Permissions (RBAC)

YeneSchool uses role-based access control with 10 roles:

| Role | Access Level |
|------|-------------|
| **Super Admin** | Full system access |
| **School Owner** | School management |
| **Director** | Academic management |
| **Supervisor** | Multi-branch oversight |
| **Registrar** | Student management |
| **Teacher** | Teaching and grading |
| **Student** | View own data |
| **Parent** | View child's data |
| **Finance Officer** | Financial management |
| **Storekeeper** | Inventory management |

## Subscription Management

Manage your subscription and billing:

1. Navigate to **Settings → Subscription**
2. View current plan and usage
3. Upgrade or downgrade plans
4. Manage payment methods
5. View billing history

> [!NOTE]
> Subscription features are managed by the Super Admin or School Owner. Contact support for plan changes.
