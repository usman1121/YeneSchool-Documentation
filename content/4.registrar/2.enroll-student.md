# Student Enrollment

Enrolling students is a core registrar function. YeneSchool supports both manual enrollment and bulk CSV import.

## Manual Enrollment

1. Navigate to **Enroll Student** in the sidebar
2. Fill in student details:
   - **First Name**
   - **Middle Name** (Father's name in Ethiopian naming convention)
   - **Last Name** (Grandfather's name, optional)
   - **Gender** — Male or Female
   - **Phone** — Student or guardian phone number
   - **Fayda Number (FAN)** — 12-digit national ID
   - **Email** — Optional
   - **Current Class** — Select grade level
   - **Parent/Guardian Info** — Name, phone, relationship
3. Click **Enroll**

## What Happens After Enrollment

1. A student profile is created
2. Login credentials are generated automatically
3. The student is added to the selected class
4. Parents receive notification (if configured)

## Required Information

Every student **must** have a Fayda Number (FAN). This is a 12-digit national ID used for identification and login.

> [!WARNING]
> Rows without a FAN will be rejected during bulk import. Always verify FAN numbers before enrollment.
