# Bulk Import Students

When enrolling a whole class or an entire school worth of students at once, use the **Bulk Import** feature. This imports student records from a CSV file, creates their profiles, and generates login credentials automatically.

## Navigate to Bulk Import

1. From the Registrar Dashboard, click **Manage Students**, then navigate to **Director → Bulk Upload**, or go directly to **Bulk Upload** from the side menu.
2. Make sure the **Import** tab is selected.
3. Switch the upload type to **Students (Auto)**.

## Step 1 — Download the Template

1. Click **Download Template**.
2. Open the downloaded `template_students-auto.csv` in Excel or Google Sheets.

> [!IMPORTANT]
> Always start from the official template. Do not rename or remove any column headers.

## CSV Column Reference

| Column | Required | Description |
|---|---|---|
| `first_name` | ✅ | Student's given name |
| `middle_name` | ✅ | Father's name (used as middle name in Ethiopian naming) |
| `last_name` | ❌ | Grandfather's name (optional) |
| `gender` | ✅ | `Male` or `Female` |
| `phone` | ✅ | Student or guardian phone number (used for login) |
| `fan` | ✅ | Fayda Number — 12-digit national ID |
| `email` | ❌ | Student email address (optional) |
| `current_class` | ✅ | Grade level, e.g. `Grade 5` or `5` |
| `parent_name` | ❌ | Guardian full name |
| `parent_phone` | ❌ | Guardian phone number |
| `mother_name` | ❌ | Mother's full name |
| `mother_phone` | ❌ | Mother's phone number |
| `roll_number` | ❌ | Class roll number |

> [!WARNING]
> Every student **must** have a `fan` (Fayda/FAN) column with a valid 12-digit number. Rows without a FAN will be rejected. The CSV upload will not proceed if the `fan` column header is missing entirely.

## Step 2 — Fill In the Template

- One student per row.
- Use the exact grade labels your school uses (e.g., `Grade 8`, `8`, `KG 2`).
- Grades must fall within your school's configured grade range. Out-of-range grades will be flagged before upload.
- Do not include row numbers in the first column — the system strips them automatically, but it is cleaner without them.

## Step 3 — Upload the File

1. Select the correct **Academic Year** from the dropdown.
2. Drag and drop your CSV onto the upload area, or click **Choose File** to browse.
3. The system shows a **preview table** of the first 10 rows. Verify names, grades, and FAN numbers look correct.
4. If you see a warning banner such as *"Staff data detected"* or *"Fayda header missing"*, do not proceed — fix the file first.

## Step 4 — Confirm Import

1. Click **Import**. For large files (100+ students), the import runs as a **background job** and you will see a live progress bar.
2. When complete, the results panel shows:
   - **Successful** — imported and credentials created
   - **Skipped** — duplicate records already in the system
   - **Failed** — rows with errors (name missing, invalid FAN, etc.)
3. Download the **Import Report** CSV to get all generated usernames and temporary passwords.

> [!TIP]
> Print the credentials report and sort it by class before handing credentials to homeroom teachers for distribution.
