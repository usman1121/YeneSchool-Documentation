# Announcements & Messaging

YeneSchool provides multiple communication channels to keep students, parents, and teachers informed. Create school-wide announcements, send direct messages, and manage the communication book.

## Creating Announcements

1. Navigate to **Announcements** in the sidebar
2. Click **Create Announcement**
3. Set the details:
   - **Title** — Short headline for the announcement
   - **Content** — The full message
   - **Audience** — All users, specific role, specific class, or specific user
   - **Channel** — In-app, push notification, email, SMS, or Telegram
   - **Priority** — Normal or High
4. Click **Publish**

## Announcement Channels

| Channel | Description |
|---------|-------------|
| **In-App** | Shows as a notification in the app |
| **Push** | Sends a push notification to mobile devices |
| **Email** | Sends an email to recipients |
| **SMS** | Sends a text message to phone numbers |
| **Telegram** | Sends a message via Telegram |

## Messaging

Send direct messages to individuals or groups:

1. Navigate to **Messages** in the sidebar
2. Click **New Message**
3. Select the recipient (student, parent, teacher, or group)
4. Write the message
5. Click **Send**

## Communication Book

The communication book records all messages between teachers, students, and parents:

- Access from the **Parent Dashboard → Messages**
- Teachers can reply to parent messages
- All messages are timestamped and archived

> [!NOTE]
> Parents can enable push notifications so they receive instant alerts for announcements and messages — no need to log in every time.

## Message Preferences

Users can manage their notification preferences:

1. Go to **Settings → Notification Preferences**
2. Select which channels to receive notifications on
3. Set preferences for different message types
4. Click **Save**
