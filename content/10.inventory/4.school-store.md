# School Uniform & Book Store

YeneSchool includes a dedicated point-of-sale store module for schools that sell uniforms, custom exercise books, PE kits, and school badges directly to families.

---

## 1. Configuring Store Items & Prices

1. In **Inventory → Store Items**, tag items that are available for direct student/parent purchase.
2. Define the **Retail Selling Price (ETB)** and available **Sizes / Variants** (e.g., *Uniform Blazer: Size 28, 30, 32, 34, 36*).
3. Set maximum purchase limits per student if supply is restricted during peak enrollment season.

---

## 2. Processing a Store Sale

1. Navigate to **Inventory → Store POS / Sales Counter**.
2. Search and select the **Student** (by Name or Student ID).
3. Add requested items to the sale cart (e.g., *2x School Polo Shirt, 1x PE Tracksuit, 10x 50-Leaf Exercise Books*).
4. Select the **Payment Method**:
   - **Cash:** Cash handed at counter.
   - **Bank Transfer / Telebirr / CBE Birr:** Enter transaction reference code.
   - **Add to Student Fee Balance:** Bills the items to the student's monthly finance account.
5. Click **Complete Sale & Print Receipt**.
6. The system prints a customer sales receipt and updates store stock in real time.
