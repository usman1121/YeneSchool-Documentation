# Managing Catalog & Categories

A well-structured catalog is the foundation of accurate school inventory tracking.

---

## 1. Creating Item Categories

1. Go to **Inventory → Categories** in the sidebar.
2. Click **+ Add Category**.
3. Enter category details:
   - **Category Name:** (e.g., *Science Lab Chemicals, Mathematics Textbooks, Student Uniforms*).
   - **Category Code / Prefix:** (e.g., *LAB, TXT-MATH, UNI*).
   - **Description:** Brief scope of items in this category.
4. Click **Save Category**.

---

## 2. Registering New Inventory Items

1. Navigate to **Inventory → Items Catalog**.
2. Click **+ Register Item**.
3. Fill in the item specifications:

| Field Name | Type / Format | Purpose & Example |
| :--- | :--- | :--- |
| **Item Name** | Text | Distinct name (e.g., *Grade 9 Biology Textbook 2016 Edition*). |
| **Item SKU / Code** | Alphanumeric | Unique inventory identifier (e.g., *TXT-BIO-09*). |
| **Category** | Dropdown | Select from created categories. |
| **Unit of Measurement** | Dropdown | Pieces, Boxes, Sets, Litres, Reams, Pairs. |
| **Initial Quantity** | Number | Current physical count in store. |
| **Unit Purchase Cost** | Currency (ETB) | Cost per unit for balance valuation. |
| **Reorder Threshold** | Number | Minimum count before warning alert (e.g., *15 Reams*). |
| **Storage Location** | Text | Store room shelf / bin location (e.g., *Shelf B-3*). |

4. Click **Save Item**. The item is immediately available for stock transactions and requisitions.
