# Overview

This guide covers the complete setup and configuration process for YeneSchool — from installation to your first day of teaching.

## Installation Methods

### Docker (Recommended)

```bash
docker compose up -d --build
```

### Manual Setup

```bash
cd backend && npm install && npx prisma migrate deploy && npm run start:dev
cd frontend && npm install && npm run dev
```

## Configuration Checklist

1. **School Settings** — Name, address, calendar type
2. **Academic Years** — Create year and terms
3. **Classes & Sections** — Set up class structure
4. **Student Enrollment** — Add students
5. **Timetable** — Build weekly schedule
6. **AI Assistant** — Configure AI service
7. **Notifications** — Set up channels
