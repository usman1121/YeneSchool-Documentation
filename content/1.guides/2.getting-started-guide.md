# Getting Started Guide

Welcome to YeneSchool! This complete walkthrough covers everything you need to get started.

## Quick Overview

YeneSchool is a full-stack school management platform with Next.js, NestJS, PostgreSQL, Redis, BullMQ, AI Assistant, offline-first PWA, and 5-language support.

## Installation

### Docker (Recommended)

```bash
docker compose up -d --build
```

The app is served at `http://localhost:8000`.

### Manual

```bash
cd backend && npm install && npx prisma migrate deploy && npm run start:dev
cd frontend && npm install && npm run dev
```

## Role-Based Access

| Role | Main Responsibilities |
|------|----------------------|
| **School Director** | System-wide configuration |
| **School Owner** | School management, branch creation |
| **Director** | Academic years, timetables, staff |
| **Registrar** | Student enrollment, bulk import |
| **Teacher** | Attendance, grades, lessons |
| **Finance Officer** | Fees, payments, payroll |
| **Parent** | Monitor child, pay fees |
| **Student** | View timetable, grades |
| **Supervisor** | Multi-branch oversight |
| **Storekeeper** | Inventory management |
