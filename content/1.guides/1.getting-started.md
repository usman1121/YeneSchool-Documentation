# Getting Started

Welcome to **YeneSchool** — the complete school management platform for Ethiopian schools. This guide walks you through everything from installation to your first day of teaching.

## What You'll Learn

By the end of this guide, you'll know how to:

1. **Install** YeneSchool using Docker or manually
2. **Configure** your school, academic year, and users
3. **Navigate** the dashboard for your role
4. **Manage** students, classes, and academic records
5. **Use** the AI assistant and communication tools
6. **Deploy** to production and maintain the system

## Step 1: Install

### Docker (Recommended)

```bash
docker compose up -d --build
```

The app is served at `http://localhost:8000`.

### Manual

```bash
# Backend
cd backend && npm install && npx prisma migrate deploy && npm run start:dev

# Frontend
cd frontend && npm install && npm run dev
```

## Step 2: Configure Your School

1. Log in as a **School Owner** or **School Director**
2. Navigate to **Settings → School Settings**
3. Set:
   - School name and address
   - Calendar type (Ethiopian or Gregorian)
   - Active academic year and term
4. Click **Save**

## Step 3: Set Up Academic Years

1. Navigate to **Academic Years**
2. Create the academic year with start/end dates
3. Add terms (First, Second, Third)
4. Set the active term

## Step 4: Create Classes and Add Students

1. Navigate to **Classes** and create classes/sections
2. Enroll students manually or via bulk CSV import
3. Assign teachers to classes and subjects

## Step 5: Build the Timetable

1. Navigate to **Timetable**
2. Create periods for each class
3. Assign subjects and teachers
4. Configure bell schedules

## Step 6: Start Teaching

1. Teachers mark attendance
2. Enter grades and create lesson plans
3. Assign and grade homework

## Step 7: Communicate

1. Create announcements for parents and students
2. Send messages through the communication book
3. Configure notification preferences
